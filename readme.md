QuietQuill is a personal journaling app designed to help you reflect on your thoughts and emotions. It features a beautiful calendar view, a dedicated space for writing notes, and sentiment analysis to provide insights into your emotional state.

## Features

-   **Interactive Calendar:**
    -   Browse through years and months with ease.
    -   Select specific dates to view or add notes.
    -   Visually see which dates have saved notes.
-   **Journaling:**
    -   Write daily entries with a title and detailed text.
    -   Automatic saving of your notes as you type.
    -   Load saved notes for each date.
-   **Sentiment Analysis:**
    -   Analyze the sentiment of your journal entries.
    -   Get a quick overview of your emotional tone (positive, negative, neutral).
    -   View a monthly sentiment chart.
-   **AI-Powered Suggestions:**
    -   Generate suggestions based on your journal entries.
    -   Get prompts and ideas to help you reflect further.
- **Data Persistance:**
    - The app saves the notes and sentiment scores to files.

## Tech Stack

-   **Swift:** The primary programming language for iOS development.
-   **SwiftUI:** The modern UI framework for building user interfaces.
-   **Xcode:** The integrated development environment (IDE) for iOS development.
-   **ngrok:** Used to create a secure tunnel to the backend server for sentiment analysis and suggestion generation.
- **Charts:** Used to create the sentiment chart.

## Getting Started

### Prerequisites

-   **macOS:** A Mac computer running macOS.
-   **Xcode:** Xcode 15.0 or later installed from the Mac App Store.
-   **iOS Device (Optional):** An iPhone or iPad for testing on a physical device.
- **Ngrok:** Ngrok installed and running.

### Installation

1.  **Clone the Repository:**
    ```bash
    git clone [repository-url]
    cd QuietQuill
    ```
    *Replace `[repository-url]` with the actual URL of your repository.*

2.  **Open in Xcode:**
    -   Open Xcode.
    -   Go to `File > Open...`.
    -   Navigate to the `QuietQuill` folder.
    -   Select `QuietQuill.xcodeproj`.
    -   Click "Open."

3.  **Run the App:**
    -   Select a simulator or a connected iOS device as the run destination.
    -   Click the "play" button to build and run the app.

4. **Ngrok:**
    - Run ngrok and make sure that the url is correct.
    - Update the url in the `ContentView.swift` file if it changes.
